# Remelyn Delit — Video Editor Portfolio

Static portfolio site built from the "Remelyn Portfolio" Canva deck. Plain HTML/CSS/JS with GSAP + ScrollTrigger and Lenis for motion; no build step.

- `index.html`, `style.css`, `main.js` — the site
- `assets/` — portrait, collage, and `v/` work clips (cut from the Canva page exports)
- `scripts/cut.sh` — re-cuts the clips from fresh Canva MP4 exports of pages 3 and 4

Run locally: `python3 -m http.server 5173` then open http://localhost:5173.

Deployed with GitHub Pages from `main`.
